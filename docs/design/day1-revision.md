# 第一天改版提案：偷情張力、三人戲、隱藏結局

> 規格見 [../SPEC.md](../SPEC.md)，美術紀錄見 [../art/plan.md](../art/plan.md)。
> 這份文件整理 2026-11-10 試玩後的評估，以及這次要實作的內容。

## 1. 評估：現在的問題

### 1.1 「偷情」的張力太弱（最大的問題）
- 流程是「跟男角互動 → 主管剛好路過 → 小遊戲」。主管出現的時機和難度，跟你剛才和男角多親近完全無關，玩起來像兩個分開的遊戲，不像「偷偷戀愛差點被抓」。
- 小遊戲裡只有女主在動，男角站在旁邊沒有作用。沈硯在茶水間「擋在前面」只是成功台詞，不是機制。

### 1.2 劇情
- 兩位男角一整天都沒有同場過，少了「同時被兩個人在意」的張力，也沒有隱藏結局需要的鋪陳。
- 結局只有三種：周以澄、沈硯、被約談。兩人好感都很低時仍然是「平安下班，陪你走到電梯口的是某人」，不合理。
- 周以澄白板上的「第三行」沒有回收。
- 午休第二個選項（「謝謝你」或「明天也一起？」）沒有任何效果。（這次不處理，留給多日劇情。）

### 1.3 重玩動機
- 一輪約 10 分鐘、只有一天，玩完就沒有理由再玩。

## 2. 這次要做的內容

### 2.1 越大膽越危險（熱度）
- 選項可以標記為「大膽」（`risk: 1`）。大膽的選項好感加得多，但會累積**熱度**。
- 熱度讓下一次主管事件更難：
  - 主管視線範圍每點熱度 +30%。
  - 突襲的預兆時間每點熱度縮短 20%（除以 1 + 0.25 × 熱度）。
- 主管事件結束後熱度歸零。
- 介面：便利貼上標示「大膽」；會議邀請彈窗的提示加一句「剛剛太明顯了，經理比平常警覺」。
- 標記為大膽的選項：

  | 時段 | 選項 |
  | --- | --- |
  | 09:00 座位區 | 「你是不是根本沒壞？」 |
  | 10:30 茶水間 | 「你怎麼知道我喝什麼？」 |
  | 15:00 影印室 | 「你手好冰。」、拍拍他的頭 |
  | 17:30 會議室 | 周以澄「好啊，你請。」、沈硯「為什麼幫我？」 |

### 2.2 男角救場
- 每天一次：被主管抓到時，如果該事件男角的好感 ≥ 60，他會出來救場，不加約談次數。
- 周以澄：搶著說是自己在問問題，把主管的注意力引走。
- 沈硯：把一份文件塞給主管，說法務要他馬上簽。
- 結局簽核單的「躲過主管」次數會把救場算進去。

### 2.3 三人同場戲
- **10:30 茶水間**：沈硯換完咖啡後，周以澄衝進來。新選項：
  1. 「沈律師泡的咖啡很好喝喔。」
  2. 把咖啡推到周以澄面前：「你喝。」（**牽線**）
  3. 「你們兩個擋到咖啡機了。」
- **12:30 午休**：新增第三個選項「叫周以澄一起上去找沈硯」（**牽線**，兩人都不加好感）。
- 兩個牽線選項都不是第一個選項，正常遊玩不會誤入。

### 2.4 結局
判斷順序：

| 順序 | 結局 | 條件 |
| --- | --- | --- |
| 1 | 被約談 | 約談滿 3 次（原本就有） |
| 2 | **隱藏：最佳助攻** | 茶水間和午休都選了牽線，且兩人好感都 < 70（沒跟任何人走太近） |
| 3 | 一個人下班 | 兩人好感都 < 40 |
| 4 | 平安下班（周以澄或沈硯） | 其他情況，好感高的人（原本就有） |

- 隱藏結局在 17:30 進入專屬的會議室劇情：兩人在白板前分工，白板第三行是周以澄寫的「問沈律師喜歡喝什麼」。之後一樣是最終關。
- 周以澄的好結局最後補上白板第三行的回收。
- 結局 CG：周以澄、沈硯、隱藏結局各一張。
