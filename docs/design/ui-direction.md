# UI 方向

> 依據兩個設計工具整理：**design-taste-frontend**（taste skill v2，反「AI 味」的美術方向與禁用清單）與 **ui-ux-pro-max**（UX、無障礙、色彩、字體規範）。
> 規格見 [../SPEC.md](../SPEC.md)。

## 1. 核心概念

> **女主辦公桌上的東西，就是整個介面。**

每個 UI 元件都借用一個真實的辦公室物件。換成任何一款戀愛遊戲，這句話都不成立，所以它是這款遊戲自己的概念，不是類型的預設樣子。

| 介面需求 | 辦公室物件 | 說明 |
| --- | --- | --- |
| 時間、進度 | **打卡單** | 右上角一張窄卡，09:00–18:00 一格一格蓋章。下方 3 格「主管約談」章就是懷疑值。 |
| 對話框 | **公司內部通訊軟體視窗** | 標題列是說話者名字加「已讀／輸入中」狀態（好感度提示）。女主的內心獨白用另一種底色，像「備忘錄」。 |
| 選項 | **便利貼** | 2–3 張便利貼貼在對話框上方，略微旋轉（±1.5°），聚焦或滑過時轉正並抬起。 |
| 主管警報 | **會議邀請彈窗** | 「賈正經 邀請你參加：臨時會議（現在）」，紅色是全遊戲唯一出現紅色的地方。掩護按鈕與 1/2/3 掩護方式在彈窗內。 |
| 結局 | **簽核單** | 結局卡蓋上「核准」或「退件」大章，列出今日結果。 |
| 標題畫面 | **員工識別證** | 識別證上是遊戲名字，「開始上班」是唯一的按鈕。 |

## 2. 色彩

色彩比例參考 ui-ux-pro-max 的「浪漫」色票，調整成辦公室的素色底。taste skill 禁止米黃底配赭紅、紫色系，這裡都沒有用。

| 角色 | Token | 色碼 | 用在 |
| --- | --- | --- | --- |
| 底色 | `--paper` | `#F7F7F5` | 舞台四周、卡片底。偏冷的紙白，不是米黃。 |
| 墨色 | `--ink` | `#14161A` | 所有內文。 |
| 次要墨色 | `--ink-2` | `#4A4F57` | 時間、說明等次要文字（對 `--paper` 對比 ≥ 7:1）。 |
| 面 | `--panel` | `#E9EBEE` | 通訊軟體視窗、打卡單的底，靠色階和底色區分，不用線或陰影。 |
| 強調（心動） | `--heart` | `#BE185D` | 「輸入中」狀態、心動台詞的名字、主要按鈕。全畫面同時最多出現在兩處。 |
| 警報 | `--alert` | `#DC2626` | 只用在主管警報與約談章。 |
| 便利貼 | `--note` | `#FBE38E` | 只當便利貼的色面，不當頁面底色。 |
| 內心獨白 | `--memo` | `#DCE7F2` | 女主內心獨白的底。 |

- 按鈕文字與底色對比 ≥ 4.5:1。`--heart` 上用白字（約 6:1）。
- 便利貼上的字用 `--ink`。

## 3. 字體

- **一個字族：Noto Sans TC**（Google Fonts，400 / 500 / 700）。ui-ux-pro-max 推薦的 Great Vibes 與 Cormorant 沒有中文字形，不採用。
- 可選第二字體：手寫體只用在便利貼上（例如 Klee One 或 LXGW WenKai TC，實作時確認授權與檔案大小）。全遊戲最多兩種字體。
- 尺寸（邏輯解析度 1280×720）：
  | 用途 | 大小 | 行高 |
  | --- | --- | --- |
  | 對話內文 | 22px | 1.6 |
  | 說話者名字 | 18px／700 | 1.3 |
  | 選項便利貼 | 20px | 1.45 |
  | 打卡單、狀態 | 16px | 1.4 |
  | 結局標題、標題畫面 | 56–72px／700，字距 −0.02em | 1.05 |
- 不用全大寫小字標籤、不用等寬字、不在標題裡用特別樣式強調某個字。

## 4. 版面

- 16:9 舞台，邏輯解析度 1280×720，依視窗等比縮放，四周補 `--paper`。
- 圖層：底層 PixiJS 畫布（場景、角色、主管小遊戲），上層 Vue UI。
- 位置：
  - 對話視窗：底部，左右各留 32px 邊距，高約 200px。
  - 便利貼選項：對話視窗上方，靠右排列。
  - 打卡單：右上角。
  - 會議邀請彈窗：主管事件時從右下滑入，不遮住小遊戲中女主與主管的路線。
- 左右外邊距一致；元件之間用間距與色階分隔。

## 5. 禁用清單（taste skill 規則）

- 不用漸層、光暈、毛玻璃（backdrop blur）、emoji、裝飾性色塊。
- 靜止的元件不加陰影。只有真的浮在上面的東西可以有陰影：會議邀請彈窗、正在被拖動或聚焦的便利貼。
- 不用細線分隔線、1px 外框盒子。
- 不在標題上方加小標籤，不用 01／02／03 編號。
- 圖示一律用 SVG（例如 Lucide），不用 emoji。
- 按鈕統一用直角或全圓角其中一種，定案後全遊戲一致。預設：**直角**，跟紙本物件一致。

## 6. 無障礙與操作（ui-ux-pro-max 規則）

- 內文對比 ≥ 4.5:1；大字 ≥ 3:1。
- 所有操作都能用鍵盤完成：
  | 按鍵 | 動作 |
  | --- | --- |
  | Enter／Space | 推進對話 |
  | ↑↓ 或 1/2/3 | 選擇選項，Enter 確認 |
  | Space | 小遊戲中掩護 |
  | 1/2/3 | 小遊戲中選擇掩護方式 |
  | Esc | 暫停選單 |
- 清楚的聚焦外框（2px `--ink`，外推 3px），不可移除。
- 可點擊區域最小 44×44px，彼此間距 ≥ 8px。
- 對話文字放在 `aria-live="polite"` 區域；主管警報用 `role="alertdialog"`。
- 圖示按鈕都有 `aria-label`。
- 不只靠顏色傳達資訊：約談章同時有圖案與文字，好感狀態用文字（未讀／已讀／輸入中）。

## 7. 動態

- 時間：微互動 150ms，元件進出 200–300ms，退出比進入快。
- 只動 transform 與 opacity。
- 文字逐字出現（可在設定中關閉），按一下直接顯示全文。
- 便利貼聚焦：轉正、上移 4px、陰影出現。
- 會議邀請彈窗：從右下滑入 240ms；主管警報時舞台輕微震動一次（2px，120ms）。
- **`prefers-reduced-motion`：** 文字直接顯示全文、不震動、彈窗淡入、主管一格一格移動、小遊戲判定時間放寬 20%。

## 8. 佔位美術

- 男角：直立圓角矩形加名字，周以澄用暖色、沈硯用冷色，加上簡單表情文字（例如「（臉紅）」）。
- 主管：圓形頭加反光的地中海弧線，手上一顆茶葉蛋。
- 場景：Pixi 色塊畫出桌子、影印機、茶水間吧台、會議桌，並放上掩護提示道具（電話、影印機、地上的筆）。

## 9. 交付前檢查

- 1024、1280、1920 寬度截圖，逐張檢查：文字不溢出、彈窗不遮住關鍵路線、邊距一致。
- 只用鍵盤玩完一輪。
- 開啟減少動態效果玩完一輪。
- 對比度抽查：對話、便利貼、彈窗按鈕、打卡單。
- 確認沒有出現第 5 節禁用清單的任何項目。
