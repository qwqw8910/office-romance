# 第一天劇本大綱

> 規格見 [../SPEC.md](../SPEC.md)。這份是節拍大綱，**正式台詞以 [src/content/day1.ts](../../src/content/day1.ts) 為準**，這裡只記錄結構與數值。
> 好感度起始：周以澄 20、沈硯 20。懷疑值起始 0。
> 標記：`(周 +10)` 表示周以澄好感 +10；`【主管：模式】` 表示觸發小遊戲；「合適掩護」是該場景判定為成功的掩護方式。

## 開場 08:58

- 林晏晴打卡進門。桌上已經貼著賈正經的便利貼：「晏晴～這個很簡單吧？下班前給我 :)」
- 內心獨白：「這是本週第四個『很簡單』。」
- 教學提示：用 Enter、Space 或點擊推進對話。

## 時段 1｜09:00 晨會後的座位區（周以澄）

- 周以澄抱著筆電跑來，說系統壞了要她幫忙看。其實只是想找她說話。
- 選項：
  1. 「你是不是根本沒壞？」(周 +10) → 他臉紅承認。
  2. 「我很忙，找別人。」(周 −5)
  3. 默默幫他把音樂關掉（其實沒壞）。(周 +5)
- **【主管：巡邏】教學關。** 合適掩護：**講電話**（桌上有電話）。
  - 教學提示：「看地上的路線，在他看過來之前按 Space 掩護。」
  - 成功：周以澄小聲說「晏晴姐好厲害……」(周 +5)
  - 被抓小劇場：賈正經：「欸，年輕人很有活力嘛！那這份週報也給你們一起做。」兩人一起多一份工作。

## 時段 2｜10:30 茶水間（沈硯）

- 林晏晴在泡咖啡，沈硯默默把她的杯子換成他已經泡好的那杯。「你的太淡。」
- 選項：
  1. 「你怎麼知道我喝什麼？」(沈 +10) → 「你每天都喝一樣的。」
  2. 「謝謝，但我自己來就好。」(沈 −5)
  3. 回敬他一包餅乾。(沈 +5)
- **【主管：突襲】** 預兆：「啪嗒、啪嗒……一股茶葉蛋味飄來。」合適掩護：**講電話**。
  - 成功：沈硯面不改色地擋在她前面，低聲說「走了。」(沈 +5)
  - 被抓小劇場：賈正經剝著茶葉蛋：「你們在講法務的事嗎？那順便幫我看一下我家房東的合約。」

## 時段 3｜12:30 午休頂樓（玩家二選一，無主管）

- 喘息時段。林晏晴上頂樓吃便當，內心吐槽早上的事。
- 選項（決定和誰共度午休）：
  1. 傳訊息約周以澄。(周 +10) → 他帶了兩杯珍奶，說一杯「剛好多買的」。
  2. 去找已經在頂樓抽空看書的沈硯。(沈 +10) → 他把外套墊在長椅上讓她坐。
- 後續一句對話，再一個小選項（「謝謝你。」／「明天也一起？」），兩者都不影響好感，只換一句內心獨白。

## 時段 4｜15:00 影印室（周以澄）

- 周以澄說要幫她影印，結果卡紙。兩人一起蹲下拉紙，距離很近。
- 選項：
  1. 「你手好冰。」(周 +15)
  2. 「讓開，我來。」(周 0)
  3. 拍他的頭：「下次叫我就好。」(周 +10)
- **【主管：回馬槍】** 合適掩護：**假裝影印**。
  - 賈正經走到門口說「嗯？沒人嘛」，轉身離開，停一下，再回頭：「騙你的啦！」
  - 提示（只在第一次出現）：「掩護只有 2 秒，別太早按。」
  - 成功：周以澄憋笑憋到發抖，兩人對看一眼。(周 +5)
  - 被抓小劇場：賈正經：「影印機壞了你們兩個在修喔？好啦，那以後影印機就歸你們管了。」

## 時段 5｜17:30 下班前的會議室（好感度較高者；同分則依時段 3 的選擇）

- 女主被叫去會議室收拾，那位男角已經在裡面等她。
- **周以澄線：** 他說想請她吃晚餐，緊張到把會議室白板寫滿了練習的台詞。
- **沈硯線：** 他把她今天被主管丟的那份工作已經整理好一半，「剩下的，明天一起做。」
- 選項：
  1. 答應。(該男角 +10)
  2. 開玩笑帶過。(該男角 +5)
- **【主管：突襲＋回馬槍組合】** 最終關。合適掩護：**蹲下撿筆**（會議桌下）。
  - 先突襲衝進來找遺忘的茶葉蛋，離開，然後回馬槍：「啊，還有一顆！」
  - 成功：進入結局判定。
  - 被抓小劇場：賈正經：「會議室下班後是加班專用的喔，你們是不是想加班？」懷疑值 +1。如果還沒到 3，仍然進入平安下班結局。

## 結局

### 平安下班（簽核單：核准）
- 18:00，電梯口。
- **周以澄勝出：** 他在電梯裡按住開門鍵等她，「晏晴姐，明天也要一起加油！」
- **沈硯勝出：** 他什麼也沒說，只把她的圍巾遞過來。「冷。」
- 卡片列出：兩位男角的狀態、被約談次數、「明天見」。

### 被抓結局（簽核單：退件）
- 懷疑值到 3 時立刻觸發。
- 賈正經把她叫進辦公室，一臉嚴肅：「晏晴，我都看到了。」她以為完了。
- 「你在搞副業對吧？這麼有熱情，那個副業的企劃也寫一份給我，這個很簡單吧？下班前給我。」
- 卡片列出：被約談 3 次、「明天再試一次？」
