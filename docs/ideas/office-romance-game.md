# 辦公室心動日常

## Problem Statement
怎麼讓玩家在被噁心主管不斷打斷的壓力下，靠預判與掩護，享受和一群帥哥互動的心動與刺激？

## Recommended Direction
**方向 A：一日一關的視覺小說，加上「預判主管」小遊戲。**

- **玩家體驗：** 每天從 9 點到 18 點，分成幾個時段。每個時段遇到一位男角，看對話、選選項、加好感度。主管會隨機出現，玩家要看他的動線判斷什麼時候掩護，成功就繼續，失敗就走搞笑的被抓劇情。
- **女主設定（先用 #2）：** 能力很強卻被主管壓榨的社畜。偷情是她唯一的樂趣和小小的反抗。這給了劇情情感理由，也讓主管的壓榨成為劇情動力。之後可擴充成其他設定，例如「表面乖乖牌，內心很會算計」。女主同時是玩家化身，有自己的個性與劇情。
- **主管設計：** 「好笑的噁心」，台詞誇張、動作可預測，玩家討厭他，但不會被他逼到想關遊戲。
- **被抓不是 Game Over，而是另一條劇情。** 每種被抓的方式都有搞笑結局。
- **技術：** PixiJS 加 Vue，Vue 負責對話框和 UI，PixiJS 負責場景與動畫。不使用 Three.js。專案獨立，不放在 DDgame 裡。
- **平台與尺度：** 電腦網頁；曖昧心動向（眼神、壁咚、牽手、偷親臉頰、差點被抓的緊張感）；單人遊戲。
- **爽感來源：** 和主管鬥智的刺激、收集帥哥與解鎖立繪劇情、時間管理的忙碌感、被抓到的緊張與懲罰。

## Key Assumptions to Validate
- [ ] 玩家願意為了劇情和立繪重複遊玩 — 做完第一天原型，找 3–5 位朋友試玩，看他們玩完會不會想繼續下一天。
- [ ] AI 生圖能保持角色一致 — 生圖階段先用 1–2 位男角做設定圖加表情測試，再決定要不要批次生成。
- [ ] 「預判主管」小遊戲夠有趣 — 用方塊和文字做灰盒原型，先測手感，看玩家覺得太簡單還是太難。
- [ ] 主管的惹人厭程度剛好 — 看試玩者的反應是笑還是不舒服，不舒服就調低。

## MVP Scope
**目標：只驗證「一天的流程好不好玩」。**

**包含：**
- 1 天的劇情，分成 4–5 個時段
- 2 位男角（先用佔位圖，不等 AI 生圖）
- 1 位主管，3 種出現模式
- 簡單的好感度數值
- 主管出現時的預判掩護小遊戲
- 2 個結局：成功度過一天，或被抓的搞笑結局
- 簡單的對話框 UI

**不包含：** 完整 4–6 位男角、美術成品、音效配樂、存檔、多日劇情。

## 美術規劃（最後階段）
- 規模：4–6 位男角，每人 3–4 個表情，約 20 張。
- 生圖工具：以網頁操作 gpt-image 系列（實際模型名稱到時再查證）。
- 一致性做法：每位男角先生成一張角色設定圖（正面、側面、服裝），之後的表情和場景都以該圖為參考圖用 edit 方式生成；先挑出滿意的設定圖，才批次生成表情。
- 風險：網頁操作速度慢、有張數上限、需要手動下載與命名；若張數多，改用 API 腳本批次生成。

## Not Doing (and Why)
- **Three.js 和 3D** — 這是 2D 遊戲，3D 引擎沒有優勢，只增加成本。
- **Roguelike 隨機循環** — 內容量不夠時會迅速重複，第一版先做線性劇情。
- **煮糊了式的工作倒數系統** — 容易把遊戲變成辦公室模擬，稀釋偷情主題。
- **男角各自獨有的躲藏技能** — 第一版先做好共通機制，之後再加。
- **明確成人內容** — 維持曖昧心動向，分享與上架限制少，也較容易找到玩家。
- **多人與連線功能** — 單人遊戲，不重複 DDgame 的路線。
- **生圖與批次美術** — 放到最後階段，先用佔位圖確認玩法成立。
